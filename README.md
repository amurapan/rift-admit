# РАЗЛОМ / RIFT — Пробуждение

**Защити ядро от существа по ту сторону портала. Твоё оружие — руки перед обычной веб-камерой.**

Игра для ADMIT HACKATHON 2026, кейс «Motion: камера вместо джойстика». Направление: игра.
В бою нет очереди заданных жестов: игрок выбирает между телекинезом, защитой и разрезом, учитывая положение целей и время атаки.

## Запуск

Нужны Node.js 22.12+, npm, веб-камера и браузер с WebAssembly. Начните проверку в Chrome/Edge.

```sh
npm ci
npm run dev
```

Откройте http://localhost:5173 и нажмите «Пробудить силу». Разрешите камеру в интерфейсе браузера.
При установке скачивается готовая модель MediaPipe и копируются WASM-ресурсы. Для первой установки нужен интернет. Если загрузка прервалась: `npm run assets`.

```sh
npm run build
npm run preview
```

Для статического деплоя: установка `npm ci`, сборка `npm run build`, публикуемая папка `dist`.
На удалённом хосте камера требует **HTTPS**. Не удаляйте `dist/mediapipe/`: модель и WASM обслуживаются самим приложением.

Видео обрабатывается локально. Кадры не отправляются на сервер. Шрифт загружается с Google Fonts с системным запасным вариантом. Звук синтезируется в браузере, аудиозаписи не скачиваются.

## Как играть

1. **Калибровка.** Проведите раскрытой ладонью в удобном диапазоне влево, вправо, вверх и вниз. Когда рамка станет зелёной, подтвердите кулаком. Можно выбрать стандартный размах кнопкой.
2. **Обучение.** Перед каждой способностью показана анимация. Через три секунды сожмите кулак, чтобы начать попытку. Практика использует те же физические объекты и столкновения, что и бой: движение засчитывается только при реальном взаимодействии с целью.
3. **Старт.** После обучения уберите руку из кадра, затем удержите открытую ладонь 1,5 секунды. Также есть кнопка старта.
4. **Свободный бой.** Защищайте ядро, набирайте серии и победите Наблюдателя до истечения 2:30 активного времени.
5. **Разбор.** Посмотрите попадания, возвраты, блоки, идеальные отражения и рекомендацию тренировки. После убирания руки ладонь запускает ещё бой, кулак — рекомендованное упражнение. Есть и кнопки.

| Способность           | Движение                                                               | Результат                                                                                                                           |
| --------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Телекинез             | Щипок большим и указательным пальцами рядом с синим снарядом           | Захват снаряда. Он следует за рукой. Взмахните к противнику и разомкните пальцы во время движения для броска.                       |
| Щит                   | Раскрытая ладонь на пути атаки                                         | Щит следует за рукой. Попадание вскоре после поднятия отражает снаряд обратно; обычный блок поглощает его.                          |
| Разрез                | Быстрый взмах открытой ладонью через кристалл                          | Урон вдоль фактической траектории руки. Можно рассечь несколько целей. Работают горизонтальные, вертикальные и диагональные взмахи. |
| Расширение территории | При 100% энергии сблизить две раскрытые ладони и удержать одну секунду | Уничтожает текущие угрозы, замедляет новые атаки на 6,5 секунды и открывает глаз босса.                                             |

**Важна позиция руки:** щит в стороне не защитит ядро, а разрез мимо цели не нанесёт урон. Курсор зеркальный, как изображение камеры. Для стабильности координаты вычисляются по ладони, а не по кончикам пальцев.

Щит расходует энергию и восстанавливается при опущенной/сжатой руке. Снаряд заряжается после 0,65 секунды удержания и перегревается после 4,8 секунды. Заряженный бросок пробивает броню кристалла; для обычного разреза нужны два попадания отдельными взмахами. Бросок получает небольшую помощь с наведением, только если направлен в сторону противника.

Для основных способностей нужна одна рука; вторая используется для секретного приёма. Готовность территории видна в панели и подсказке.

## Три фазы

- **0:00–0:30 — Первые трещины.** Синие снаряды и обычные кристаллы, редкие атаки.
- **0:30–1:05 — Вторжение.** Бронированные кристаллы, парные атаки и более быстрый темп.
- **С 1:05 — Пробуждение.** Наблюдатель выпускает залпы с предупреждением. После залпа глаз открывается для разрезов. Возвращённые снаряды могут пробить его защиту и в закрытом состоянии.

Для победы нужно уничтожить Наблюдателя, сохранив ядро. Разрушение ядра или истечение времени — поражение. При потере руки, непригодном положении кисти, остановке кадров или уходе на другую вкладку симуляция приостанавливается. Открытая, но неверно расположенная рука не останавливает бой.

## Обязательный режим «ошибка»

Подсказки связаны с измеренной геометрией и исходом действия, а не выдаются случайно:

| Ошибка                                | Что измеряется                                                         | Конкретная подсказка                                 |
| ------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------- |
| Кисть обрезана, слишком далеко/близко | Границы точек и размер ладони                                          | Вернуть кисть целиком / приблизить / отодвинуть      |
| Незавершённый щипок рядом со снарядом | Положение рядом с целью, раскрытие пальцев, расстояние между кончиками | Плотнее свести большой и указательный пальцы         |
| Слабый бросок                         | Скорость ладони при размыкании щипка                                   | Разомкнуть пальцы во время взмаха, до остановки руки |
| Слишком долгое удержание              | Время удержания снаряда                                                | Бросить до перегрева                                 |
| Разрез мимо                           | Отсутствие пересечения траектории с целью                              | Провести светящуюся линию через кристалл             |
| Согнутые пальцы рядом с кристаллом    | Число выпрямленных пальцев                                             | Раскрыть ладонь перед разрезом                       |
| Пропущенная атака                     | Снаряд достиг ядра                                                     | Поставить ладонь на пунктирную траекторию            |
| Истощённый щит                        | Запас энергии защиты                                                   | Сжать руку для восстановления                        |

После боя программа выбирает персональное упражнение по статистике: слабые броски и неточные возвраты → телекинез; промахи разрезом → точность; пропущенные атаки → позиция щита. Оно запускается отдельно от полного обучения.

## Очки и прогресс

Очки начисляются за попадания и отражения. Серия прерывается при повреждении ядра или после 5,5 секунды без успешного действия. Чередование способностей даёт дополнительные очки и быстрее накапливает энергию территории. Победа добавляет бонус за оставшиеся время и прочность ядра.

Личный рекорд и последние восемь результатов хранятся в браузере. При запрете `localStorage` игра работает, а прогресс доступен до перезагрузки. Рекорды свободной арены имеют отдельную версию и не смешиваются с очками раннего прототипа с последовательными заданиями.

## Реализация

- `src/gestures.ts` — геометрия 21 точки кисти, состояние пальцев и качество положения.
- `src/game/control.ts` — калибровка, щипок с разными порогами входа/выхода, скорость броска, непрерывная траектория разреза, поза двух рук.
- `src/game/arena.ts` — физика, столкновения, противники, босс, фазы, очки, советы и учебные сцены.
- `src/game/scene.ts` — процедурный Canvas-рисунок Наблюдателя, арены, щита, частиц, следов, разрушений и территории.
- `src/game/audio.ts` — оригинальная синтезированная музыка и эффекты через Web Audio, ограничение числа голосов, отключение звука.
- `src/tutorial.ts` — показ жеста и явная подготовка кулаком перед попыткой.
- `src/main.ts`, `src/ui.ts` — камера, экраны, итоги и жизненный цикл приложения.

MediaPipe определяет точки, а распознавание действий и игровая логика написаны командой. Физика использует небольшие шаги симуляции и проверку отрезка движения, чтобы быстрые снаряды не проходили сквозь цели. Один непрерывный разрез не может повторно ударить тот же объект и мгновенно снять всю броню. При потере трекинга не генерируется ложный бросок. Синхронный inference ограничен примерно 25 вызовами в секунду; используется GPU, с переходом на CPU при ошибке инициализации.

Графика и музыка создаются кодом. Секретный приём — тематическая отсылка к аниме с собственными эффектами, без заимствованных кадров и аудиосэмплов. Учтены маленькие экраны и настройка уменьшения движения.

## Проверка

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Для установленного Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Модульные тесты проверяют пространственные попадания/промахи, броню, силу броска, парирование, паузу, секретный приём, калибровку, победу и поражение. Отдельная симуляция проходит все фазы с захватами, парированием, разрезами и территорией до победы.

Браузерный сценарий подменяет только выход модели синтетическими точками. Он проходит физическое обучение, старт жестом, свободный бой, паузу, результат и рекомендованную тренировку. Он не подменяет столкновения и не записывает состояние боя. Отдельный тест загружает настоящие модель и WASM на виртуальной камере.

Автотесты не подтверждают точность на реальных руках. Перед сдачей проверить левую и правую руку, разное освещение, бросок, калибровку, две ладони для территории и производительность телефона. Inference пока работает в основном потоке, поэтому на слабых устройствах возможны задержки.
