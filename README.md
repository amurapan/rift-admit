# РАЗЛОМ / RIFT — первая печать

**Сложи печать. Сожми пространство. Защити ядро от существа по ту сторону.**

Игра для ADMIT HACKATHON 2026, кейс «Motion: камера вместо джойстика».
Направление — **игра**. Распознавание рук, последовательностей жестов и нарисованного символа работает в браузере через обычную веб-камеру.

## Запуск

Нужны Node.js 22.12+, npm и веб-камера. Для проверки и демонстрации используйте Chrome. В [официальных требованиях MediaPipe для веба](https://developers.google.com/edge/mediapipe/solutions/setup_web) указаны Chrome и Safari.

```sh
git clone https://github.com/amurapan/rift-admit.git
cd rift-admit
npm ci
npm run dev
```

Откройте http://localhost:5173. Нажмите «Войти в разлом» и разрешите камеру.
Первое нажатие также включает звук и запрашивает полноэкранный режим. Если браузер его не поддерживает или отклоняет запрос, сцена занимает всё окно. Выйти из fullscreen можно через Escape или кнопку вверху.

Проверено с Node.js 22.22.2 и npm 11.14.1 на чистой копии репозитория. Пользователю опубликованной версии Node.js не нужен. API-ключи, аккаунт и серверная база данных не требуются.

При установке скачивается готовая модель MediaPipe и копируются WASM-ресурсы. Для первой установки нужен интернет; повторная загрузка ресурсов — `npm run assets`.

```sh
npm run build
npm run preview
```

Для просмотра сборки откройте http://localhost:4173. `npm run preview` используется для локальной проверки. Для публикации нужны статические файлы из `dist`, как описано в [руководстве Vite](https://vite.dev/guide/static-deploy.html).

Статический деплой в корень сайта: `npm ci`, `npm run build`, публикуемая папка `dist`. Для камеры на удалённом хосте нужен **HTTPS**. Файл `dist/hand-worker.js` и папку `dist/mediapipe/` нужно публиковать вместе с приложением.

Кадры обрабатываются локально и не отправляются на сервер. Шрифт загружается с Google Fonts; предусмотрен системный запасной вариант. Графика и звук создаются кодом, аудиозаписи не загружаются.

## Законченный сценарий

1. **Пробуждение.** Из темноты появляется Наблюдатель. После появления подсказки поднимите указательный и средний пальцы на обеих руках. Держите кисти рядом, без перекрытия. Когда печать примется, разведите руки в стороны — разорвите завесу. Кнопка «К обучению» позволяет пропустить вступительный ритуал.
2. **Четыре коротких урока на арене.** Посмотрите показ, затем подтвердите готовность кулаком. Приложение требует фактического попадания способностью; жест из предыдущего урока не завершает следующий автоматически. Территория в обучении уже заряжена.
3. **Бой.** После обучения уберите руку, затем удержите открытую ладонь 1,5 секунды. Можно использовать кнопку. За 2:30 активного времени нужно сохранить ядро и победить босса.
4. **Результат.** Очки, серия, попадания волной и разрезом, отражения, территории и конкретная рекомендация тренировки. После убирания руки ладонь запускает новый бой, кулак — рекомендованный урок. Есть и кнопки.

Прохождение обучения запоминается в браузере: при следующем входе доступно «Сразу в бой».
«Печати / помощь» открывает справочник и приостанавливает бой. Там можно сразу запустить отдельную тренировку разреза или круга, а также настроить удобный размах кисти: провести раскрытой ладонью по горизонтали и вертикали, затем подтвердить кулаком.

## Способности и комбинации

| Техника                   | Действия                                                                                                                              | Результат                                                                                                                                              |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Сжатие пространства**   | Покажите открытую ладонь. Сожмите кулак у группы целей, удержите около 1–2 секунд, затем полностью раскройте ладонь.                  | Воронка притягивает окружающие обломки и врагов. Раскрытие выпускает расширяющуюся ударную волну. Полный заряд пробивает броню.                        |
| **Отражение**             | Остановите открытую ладонь на пути атаки.                                                                                             | Вращающаяся печать блокирует попадание. Свежая печать возвращает снаряд боссу. Защита расходует энергию; опустите или сожмите руку для восстановления. |
| **Разрез реальности**     | Удержите указательный и средний пальцы примерно треть секунды, затем быстро проведите ими или открытой ладонью через цель.            | Появляется светящаяся трещина. Через короткую задержку она наносит урон по фактической траектории. Броня требует двух отдельных разрезов.              |
| **Расширение территории** | При 100% энергии сблизьте две раскрытые ладони. Щипком нарисуйте крупный круг, отпустите пальцы, затем разведите две открытые ладони. | Печать перестраивает арену, уничтожает текущие угрозы, замедляет новые атаки на 7,5 секунды и усиливает разрезы.                                       |

Для разреза нужен знак ✌: указательный и средний пальцы одной руки. Для круга нужен другой жест — щипок большим и указательным пальцами. Рисует рука с фиолетовым курсором ①; бирюзовый курсор ② показывает вторую руку. Панель сообщает распознанную позу каждой руки и текущий шаг ритуала. Для первой печати подвиньте раскрытые ладони к центру: связь между курсорами станет зелёной, когда расстояние подходит. Совмещать руки не нужно; удерживайте позу 0,7 секунды. Расстояние считается по курсорам с учётом калибровки, краткая смена нужной позы до 180 мс сохраняет накопленное удержание, но не увеличивает его. Для круга соедините большой и указательный пальцы и двигайте кистью по пунктирной направляющей; начальная точка отмечена отдельно. Штрих следует за центром ладони, чтобы размыкание пальцев не искажало рисунок. Ровный математический круг не требуется; можно рисовать в любом направлении. Незамкнутые дуги, слишком маленькие/узкие фигуры и многократные пересечения отклоняются. После ошибки отпустите щипок и начните новый штрих. В бою незаконченный ритуал истекает через 18 секунд без расхода энергии. В учебном этапе тайм-аута нет. Короткий пропуск трекинга до 300 мс замораживает действие и позволяет продолжить его с той же позой поблизости. При более долгой потере руки, изменении позы или скачке позиции незаконченный штрих сбрасывается; завершённые шаги территории сохраняются. Исчезновение руки не считается отпусканием щипка.

На обычные атаки достаточно одной руки. Две используются во вступлении и для территории. Камера остаётся маленьким зеркальным окном, основной экран занимает игровое пространство.

## Бой

- **0:00–0:30 — Первые трещины:** редкие снаряды и обычные кристаллы.
- **0:30–1:05 — Вторжение:** броня, парные атаки, более высокий темп.
- **После 1:05 — Пробуждение:** босс выпускает залпы с предупреждением и открывает глаз после атаки. Разрезы поражают открытый глаз; волны и отражённые снаряды могут пробить защиту.

Победа — уничтожение босса при живом ядре. Разрушение ядра или истечение времени — поражение. Очки начисляются за попадания и отражения, чередование техник увеличивает награду и заряд территории. Рекорд и восемь последних результатов хранятся в браузере; запрет хранения не мешает игре.

**Луч разлома:** первая атака начинается на седьмой секунде боя. Босс заряжает луч 2,8 секунды; траектория и кольцо показывают место перехвата. Нужно поставить открытую ладонь в кольцо и удерживать до выстрела (не менее 0,45 секунды). Заряд сопровождается нарастающим звуком, готовая печать становится зелёной, отражённый луч возвращается в босса. Успех даёт очки и энергию территории, а в финальной фазе наносит урон и открывает глаз на пять секунд для контратаки. Промах снимает 8% здоровья ядра. Между лучами есть 16 секунд; во время зарядки не появляются обычные волны, а начатое рисование территории откладывает следующую атаку. Активная территория поглощает луч. Пауза и потеря трекинга останавливают его таймер вместе с боем.

## Режим «ошибка» — обязательный твист

Подсказки основаны на измеренном движении и результате взаимодействия:

| Ошибка                                          | Проверка                                                               | Исправление                                                               |
| ----------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| Рука обрезана / слишком далеко / слишком близко | Границы точек и размер кисти                                           | Вернуть кисть целиком, приблизить или отодвинуть                          |
| Волна выпущена слишком рано                     | Время накопления после подтверждённого кулака                          | Удержать кулак до заполнения внутреннего кольца                           |
| Неполное раскрытие после сжатия                 | Число и положение выпрямленных пальцев                                 | Раскрыть все пальцы для выброса                                           |
| Взмах без печати                                | Отсутствие предварительного удержания указательного и среднего пальцев | Сначала сложить печать двух пальцев                                       |
| Разрез мимо                                     | Нет пересечения линии с целью                                          | Провести светящуюся линию через кристалл                                  |
| Незамкнутая печать                              | Расстояние между началом и концом относительно радиуса                 | Соединить конец с началом; начало отмечено кольцом                        |
| Слишком маленький / узкий / запутанный символ   | Размер, пропорции, радиальное отклонение и обход центра                | Увеличить круг, расширить узкую сторону или обвести центр одним движением |
| Пропущенная атака                               | Снаряд достиг ядра                                                     | Перекрыть траекторию открытой ладонью до попадания                        |
| Неудачное отражение луча | Поза, расстояние курсора до кольца, время удержания и заряд щита | Раскрыть пальцы, переместить ладонь в кольцо, поставить печать раньше или восстановить щит — в зависимости от причины |

Каждый принятый шаг меняет печать, звук и подсказку. Последний этап территории требует отдельного жеста двумя руками. Подтверждённая потеря трекинга отменяет накопление волны и разреза без ложного выброса. Краткие пропуски до 300 мс сохраняют состояние, но не засчитываются как удержание жеста. При долгом пропуске в территории сохраняется завершённый шаг, а незаконченное рисование сбрасывается без замыкания круга. Симуляция на время пропуска приостанавливается. После боя рекомендация основана на промахах, пропущенных атаках и ошибках рисования.

## Реализация

- `src/gestures.ts` — геометрия 21 точки, отдельная поза двух пальцев, качество положения.
- `src/game/control.ts` — координаты, калибровка, щипок с гистерезисом, траектория взмаха и взаимное положение рук.
- `src/game/tracking.ts` — сохранение ведущей руки при изменении порядка детекции, сглаживание курсоров и обработка коротких пропусков распознавания.
- `src/game/lesson-art.ts` — анимированный показ комбинаций.
- `src/game/ritual.ts` — вступительная печать, последовательности заклинаний, проверка нарисованного круга, исправления.
- `src/game/arena.ts` — притяжение, расширяющаяся волна, отложенный разрез, отражения, три фазы, босс, очки и учебные сцены.
- `src/game/vision.ts`, `public/hand-worker.js` — распознавание в Web Worker, передача одного кадра без очереди, отмена устаревших результатов и освобождение ресурсов.
- `src/game/scene.ts` — процедурная сцена Canvas: разрушенная архитектура, Наблюдатель, воронка, печати, трещины, осколки и территория.
- `src/game/audio.ts` — оригинальные синтезированные музыка, нарастание заряда и эффекты через Web Audio, ограничение числа голосов.
- `src/main.ts`, `src/ui.ts`, `src/immersion.css` — камера, полноэкранное представление, обучение, справочник, результаты и жизненный цикл.

MediaPipe определяет точки рук. Распознавание поз, последовательностей, фигур и взаимодействий написано командой. Физика использует небольшие шаги и проверку отрезка движения. Один непрерывный взмах не снимает два слоя брони. Обработка камеры вынесена в отдельный Web Worker. Камера запрашивается с частотой до 30 кадров в секунду; фактическая частота распознавания зависит от устройства. Одновременно обрабатывается только один кадр, очередь кадров не накапливается. Используется GPU с переходом на CPU при ошибке инициализации или трёх последовательных обработках дольше 100 мс. При явно программном WebGL (SwiftShader/llvmpipe/lavapipe) сразу выбирается CPU. Слишком старые результаты отбрасываются. Кадры поступают через `requestVideoFrameCallback` независимо от отрисовки игры; при остановке этих уведомлений включается резервный захват декодированных кадров (только пока вкладка видима); завершение обработки сразу запускает самый свежий доступный кадр. В одноручных уроках и обычном бою модель ищет одну руку, при пробуждении и доступной территории — две. Курсоры и скелет обновляются на каждом кадре экрана; адаптивное сглаживание и ограниченное предсказание движения используются только для изображения, распознавание и попадания работают с измеренными координатами. Пропуск до 300 мс сохраняет курсор и заклинание без мигания паузы: физика и накопление жестов на этот срок замораживаются. Продолжение возможно только с прежней позой поблизости; смена позы или большой скачок после пропуска сбрасывают незавершённое заклинание, не вызывая выстрела или разреза. Более долгая потеря руки включает паузу и подсказку. В «Печати / помощь» строка «Отклик рук» показывает частоту результатов, задержку от захвата кадра до результата и текущий вычислитель. Свечения и неподвижные слои сцены кэшируются; разрешение Canvas ограничено и автоматически снижается при медленной отрисовке, HTML-интерфейс остаётся чётким. Учтены уменьшение движения, узкий экран, отключение звука, отказ камеры и недоступность fullscreen.

## Проверка

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Для установленного Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Модульные тесты проверяют последовательности, геометрию круга, защиту от случайных действий, притяжение, попадания, паузу, победу, поражение и персональные советы. Симуляция проходит три фазы до победы с настоящими действиями движка.

Браузерные тесты подменяют только модель синтетическими точками: проходят вступление, четыре урока, ошибку рисования, территорию, бой, паузу, результат и повтор. Отдельный тест загружает настоящую модель на виртуальной камере. Также проверяются отказ доступа, калибровка, отсутствие fullscreen и отражение луча с подсказками о неправильной позе и позиции. На 29 сентября: 65 модульных тестов и 7 браузерных сценариев прошли; подробности и ограничения — в [отчёте проверки](docs/VERIFICATION.md).

Автотесты не подтверждают удобство и точность на реальных руках. Перед сдачей нужны проверки двух рук, позы указательного/среднего пальцев, рисунка круга, освещения и скорости на телефоне. Производительность на реальных слабых устройствах ещё требует проверки; отдельный браузерный тест проверяет, что намеренно медленное распознавание не блокирует отрисовку.
