# Разлом / RIFT

Браузерная игра для ADMIT HACKATHON 2026, кейс «Motion: камера вместо джойстика».
Управляй магией одной рукой перед веб-камерой: доставляй энергию, отражай снаряды и разрушай кристаллы.
После обучения нужно закрыть разлом за 60 секунд активного времени, поставив девять печатей.
Есть победа и поражение, три жизни, очки, серии и личный рекорд. Звук и аниме-пасхалка пока не реализованы.

## Запуск

Нужны Node.js 22.12+ и npm, веб-камера и браузер с WebAssembly (сначала проверяйте в актуальном Chrome/Edge).

```sh
npm ci
npm run dev
```

Открыть http://localhost:5173, нажать «Пробудить силу» и разрешить камеру.
Во время `npm ci` скрипт скачивает модель Hand Landmarker и копирует WASM в `public/mediapipe/`.
Для установки нужен интернет; если скачивание прервалось, повторить `npm run assets`.
Видео обрабатывается на устройстве. Модель и WASM загружаются с сервера приложения, кадры туда не отправляются.
Шрифт загружается с Google Fonts; при недоступности используется системный шрифт.

```sh
npm test
npm run build
npm run preview
```

Для деплоя: команда установки `npm ci`, сборки `npm run build`, публикуемая папка `dist`.
На удалённом хосте для камеры необходим HTTPS. Обычный HTTP по IP локальной сети не подходит для проверки камеры телефона.
В production входят модель и WASM; не удаляйте `dist/mediapipe/`.

## Сценарий

Перед каждым заклинанием в обучении показана анимация движения. Первые три секунды жесты не засчитываются; затем нужно сжать кулак примерно на полсекунды, подтверждая готовность. Это не позволяет случайно пройти следующее упражнение оставшейся открытой ладонью.

1. Соединить большой и указательный пальцы, удержать щипок и перенести светящуюся искру в центр разлома.
2. Раскрыть ладонь и удерживать её неподвижно 0,85 секунды для щита.
3. Навести курсор открытой ладони на левый круг, ненадолго задержать руку и провести её вправо по стрелке. В бою удар работает горизонтальным взмахом в любую сторону.
4. После обучения убрать руку из кадра и показать открытую ладонь на 1,5 секунды, чтобы начать испытание. Также есть кнопка старта.
5. После трёхсекундного отсчёта выполнять показанное заклинание. Задачи чередуются: энергия → щит → удар. На каждую отводится восемь секунд.
6. Каждое успешное действие ставит одну печать. Девять печатей закрывают разлом. Пропущенное действие отнимает жизнь; потеря трёх жизней или истечение общего времени завершают раунд поражением.
7. Получить итог с очками, печатями, лучшей серией и количеством каждого заклинания. Лучший результат сохраняется в этом браузере.
8. Чтобы сыграть ещё раз без обучения, убрать руку и удержать раскрытую ладонь 1,5 секунды. Обучение можно повторить отдельной кнопкой.

Следует показывать одну руку целиком. Картинка зеркальная: движение руки вправо на превью двигает курсор вправо.
На первом этапе щипок создаёт искру в положении руки; предварительно попадать в объект не нужно.
Управление после разрешения камеры работает жестами. Разрешение камеры выдаётся через интерфейс браузера.
Во время боя при потере руки, обрезанной кисти, неподходящем расстоянии, остановке кадров или уходе на другую вкладку таймеры приостанавливаются. Неверный жест при видимой кисти не останавливает время — приложение подсказывает, как исправиться.

## Очки и рекорд

За успешное заклинание начисляется 100 очков, до 50 дополнительных за скорость и до 100 за серию без пропусков (по 25 за каждое действие после первого, максимум четыре прибавки). Победа добавляет 10 очков за каждую оставшуюся секунду с округлением вверх и 100 за каждую сохранённую жизнь. Пропуск сбрасывает текущую серию, но не отнимает набранные очки.
Рекорд хранится локально в `localStorage`; это личный прогресс, не общая таблица участников. При запрете хранилища игра продолжает работать, а рекорд сохраняется до перезагрузки страницы.

## Режим «ошибка»

Каждый этап знает ожидаемое действие и оценивает его измеримые признаки:

| Условие | Подсказка |
| --- | --- |
| Кисть обрезана границей кадра | Верни кисть целиком в кадр |
| Кисть слишком маленькая | Поднеси руку ближе к камере |
| Пальцы при щипке далеко | Сведи большой и указательный пальцы |
| Щипок удерживается вне цели | Не размыкая пальцы, перенеси искру в центр разлома |
| Пальцы согнуты при защите | Выпрями четыре пальца и раскрой ладонь |
| Ладонь движется при защите | Задержи раскрытую ладонь на месте |
| Взмах короткий / медленный | Взмахни шире и быстрее |
| Взмах направлен по диагонали | Проведи ладонью горизонтально |

Собственная логика находится в `src/gestures.ts`. MediaPipe возвращает 21 точку кисти, а правила команды определяют жесты по геометрии и движению во времени. Расстояние щипка нормируется на размер ладони, геометрия учитывает пропорции видео. Используются разные пороги входа/выхода из щипка, временная выдержка, сброс при потере руки и защита от повторного успеха. Подсказки стабилизируются небольшой задержкой, чтобы не мигать каждый кадр.

## Структура и проверка

- `src/gestures.ts` — геометрия кисти и распознавание действий.
- `src/battle.ts` — таймеры, атаки, жизни, очки, завершение раунда и хранение рекорда.
- `src/tutorial.ts` — показ движения и подготовка перед каждой учебной попыткой.
- `src/main.ts` — камера, жизненный цикл модели, обучение, переходы между экранами и Canvas-арена.
- `src/style.css`, `src/battle.css` — адаптивный интерфейс и игровая панель.
- `src/gestures.test.ts` — синтетические проверки масштаба, потери трекинга, задержек, дрожания и направления взмаха.
- `src/battle.test.ts` — проверки победы, поражения, паузы, частоты кадров, начисления очков и недоступного хранилища.
- `src/tutorial.test.ts` — защита от случайного прохождения и сброс подготовки при потере руки.
- `tests/game.e2e.ts` — сценарий от обучения до победы, повтора и поражения; отдельная проверка реальной модели на виртуальной камере.
- `scripts/prepare-assets.mjs` — подготовка локальных ресурсов распознавания.

Браузерные проверки:

```sh
npx playwright install chromium
npm run test:e2e
```

Если Chromium уже установлен, можно указать его путь через переменную `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
Проверка игрового сценария подменяет только выход модели синтетическими точками кисти. Она проверяет настоящую логику жестов и весь интерфейс, но не точность камеры на реальной руке. Отдельная проверка загружает настоящие WASM и модель на виртуальном видеопотоке.

Распознавание запускается до 25 раз в секунду, сначала через GPU, при ошибке инициализации — через CPU. В этой версии inference выполняется в основном потоке; производительность на слабых телефонах требует проверки.
Автотесты геометрии не подтверждают точность модели на реальных руках: пороги нужно проверить с разным освещением, положением и размером кисти. Для ручной приёмки пройти обучение и бой, намеренно выполнить каждый жест неточно, убрать руку во время удержания, проверить паузу, отказать в доступе к камере и проверить повторный запуск.
