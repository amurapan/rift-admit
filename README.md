# Разлом / RIFT

Прототип для ADMIT HACKATHON 2026, кейс «Motion: камера вместо джойстика».
Направление: игра. Текущий этап — интерактивное обучение трём заклинаниям с результатом.
Полноценный игровой раунд, противники, звук, рекорды и аниме-пасхалка пока не реализованы.

## Запуск

Нужны Node.js 22.12+ и npm, веб-камера и браузер с WebAssembly (сначала проверяйте в актуальном Chrome/Edge).

```sh
npm ci
npm run dev
```

Открыть http://localhost:5173, нажать «Пробудить силу» и разрешить камеру.
Во время `npm ci` скрипт скачивает модель Hand Landmarker и копирует WASM в `public/mediapipe/`.
Для установки нужен интернет; если скачивание прервалось, повторить `npm run assets`.
Видео обрабатывается на устройстве. Модель и WASM загружаются с сервера приложения, кадры туда не отправляются.
Шрифт загружается с Google Fonts; при недоступности используется системный шрифт.

```sh
npm test
npm run build
npm run preview
```

Для деплоя: команда установки `npm ci`, сборки `npm run build`, публикуемая папка `dist`.
На удалённом хосте для камеры необходим HTTPS. Обычный HTTP по IP локальной сети не подходит для проверки камеры телефона.
В production входят модель и WASM; не удаляйте `dist/mediapipe/`.

## Сценарий

1. Соединить большой и указательный пальцы, удержать щипок и перенести светящуюся искру в центр разлома.
2. Раскрыть ладонь и удерживать её неподвижно 0,85 секунды для щита.
3. Провести открытой ладонью горизонтально примерно на треть кадра для удара.
4. Увидеть итог с тремя освоенными заклинаниями и временем обучения.
5. Для повторного прохождения убрать руку из кадра, затем показать открытую ладонь на 1,5 секунды; также есть кнопка повтора.

Следует показывать одну руку целиком. Картинка зеркальная: движение руки вправо на превью двигает курсор вправо.
На первом этапе щипок создаёт искру в положении руки; предварительно попадать в объект не нужно.
Управление после разрешения камеры работает жестами. Разрешение камеры выдаётся через интерфейс браузера.

## Режим «ошибка»

Каждый этап знает ожидаемое действие и оценивает его измеримые признаки:

| Условие | Подсказка |
| --- | --- |
| Кисть обрезана границей кадра | Верни кисть целиком в кадр |
| Кисть слишком маленькая | Поднеси руку ближе к камере |
| Пальцы при щипке далеко | Сведи большой и указательный пальцы |
| Щипок удерживается вне цели | Не размыкая пальцы, перенеси искру в центр разлома |
| Пальцы согнуты при защите | Выпрями четыре пальца и раскрой ладонь |
| Ладонь движется при защите | Задержи раскрытую ладонь на месте |
| Взмах короткий / медленный | Взмахни шире и быстрее |
| Взмах направлен по диагонали | Проведи ладонью горизонтально |

Собственная логика находится в `src/gestures.ts`. MediaPipe возвращает 21 точку кисти, а правила команды определяют жесты по геометрии и движению во времени. Расстояние щипка нормируется на размер ладони, геометрия учитывает пропорции видео. Используются разные пороги входа/выхода из щипка, временная выдержка, сброс при потере руки и защита от повторного успеха. Подсказки стабилизируются небольшой задержкой, чтобы не мигать каждый кадр.

## Структура и проверка

- `src/gestures.ts` — геометрия кисти и распознавание действий.
- `src/main.ts` — камера, жизненный цикл модели, этапы обучения и Canvas-арена.
- `src/style.css` — адаптивный интерфейс.
- `src/gestures.test.ts` — синтетические проверки масштаба, потери трекинга, задержек, дрожания и направления взмаха.
- `scripts/prepare-assets.mjs` — подготовка локальных ресурсов распознавания.

Распознавание запускается до 25 раз в секунду, сначала через GPU, при ошибке инициализации — через CPU. В этой версии inference выполняется в основном потоке; производительность на слабых телефонах требует проверки.
Автотесты геометрии не подтверждают точность модели на реальных руках: пороги нужно проверить с разным освещением, положением и размером кисти. Для ручной приёмки пройти все этапы, намеренно выполнить каждый жест неточно, убрать руку во время удержания, отказать в доступе к камере и проверить повторный запуск.
