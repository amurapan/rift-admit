## Описание проекта — текст для вставки

РАЗЛОМ / RIFT — браузерная игра, в которой пользователь управляет магией через обычную веб-камеру. Игрок проходит короткое обучение, защищает ядро, сражается с боссом и получает результат: очки, серию попаданий и рекомендацию для следующей тренировки. Игровые действия выполняются руками; устанавливать приложение не требуется.

Распознаются открытая ладонь, кулак, знак двумя пальцами, щипок и комбинации двух рук. Ладонь создаёт защитную печать и отражает атаки; последовательность «ладонь → кулак → ладонь» притягивает обломки и выпускает ударную волну. Два поднятых пальца подготавливают направленный разрез. Для территории нужно сблизить раскрытые ладони, нарисовать круг щипком и развести руки. Курсоры, скелет, кольца прогресса, звук и эффекты показывают, какое действие принято.

Обязательный режим «ошибка» встроен в обучение и бой. При раннем раскрытии кулака игра просит дольше накапливать заряд; незамкнутая печать сопровождается указанием соединить конец линии с началом. При отражении луча система отдельно проверяет раскрытие ладони, попадание курсора в кольцо, время удержания и запас щита, затем подсказывает конкретное исправление. Исчезновение руки не считается выпуском заклинания.

MediaPipe используется для получения точек кистей. Правила жестов, последовательности заклинаний, проверка нарисованной фигуры и физика взаимодействия реализованы в проекте. Распознавание работает в браузерном Web Worker; кадры не отправляются на сервер. Есть локальные рекорды, история боёв, калибровка размаха, процедурная графика и синтезированный звук. Доступны публичный исходный код, инструкция запуска и автоматические проверки.

## Короткий вариант, если поле ограничено

RIFT — игра с магией через веб-камеру: ладонь отражает атаки, кулак собирает обломки, знак двумя пальцами запускает разрез, а круг щипком раскрывает территорию. Есть обучение, бой с боссом и итоговый отчёт. Режим «ошибка» даёт конкретные исправления позы, позиции, времени удержания и формы круга. MediaPipe находит точки рук, собственная логика распознаёт комбинации и попадания. Кадры обрабатываются локально в браузере.

## Перед отправкой

- Указать название команды точно как при регистрации.
- Добавить HTTPS-ссылку и проверить её в новом окне Chrome: загрузка модели, разрешение камеры, жесты, результат.
- Проверить декларацию о собственных заготовках в README: если были материалы до старта, перечислить их.
- Последние исправления плавности, луч и удобство на реальной камере пока ожидают проверки игроком. Автотесты эту проверку не заменяют.
- Отправить через ссылку на Google-форму из чата организаторов до **30 сентября 2026, 23:59 по Астане (UTC+5)**. Ссылка на форму пока не предоставлена.

По присланным условиям видео не обязательно; сценарий короткой демонстрации подготовлен в [DEMO.md](DEMO.md).
